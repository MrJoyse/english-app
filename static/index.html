    👥 Роли

    В системе две роли:

    • Учитель — создаёт и редактирует уроки, управляет пользователями, видит весь прогресс и работу учеников в реальном времени.
    • Ученик — открывает уроки и выполняет задания. Учительские разделы API для него закрыты (403).

    🧑‍🎓 Пользователи

    На вкладке «Управление» создавайте учеников формой вверху: задайте имя, пароль (не короче 4 символов) и роль. Новые ученики появятся в таблице прогресса и в настройках видимости заданий.

    ➕ Создание урока

    На вкладке «Уроки» нажмите «＋ Новый урок» и заполните:

    • Название и тема — для навигации и наглядности.
    • Видео YouTube (необязательно) — ссылка любого формата: watch?v=…, youtu.be/…, shorts/… или чистый ID. В списке уроков появится значок 🎬.
    • Текст урока — материал с выделенными выражениями (см. следующий раздел). Ниже текста идёт живой предпросмотр: приложение само разбирает разметку и показывает, какие выражения нашлись и какие слова будут в задании 1.3.

    💡 Пишите текст прямо в поле — предпросмотр и счётчик «найдено: N» обновляются на каждой букве.

    ✍️ Разметка выражений

    Изучаемые выражения выделяются двойными звёздочками **…**. Внутри можно указать разбиение на части и слово для задания 1.3 через вертикальную черту |:

    РазметкаЧто получится
    **give up**Просто выражение. Для 1.1 делится автоматически по последнему слову; слово 1.3 — последнее слово.
    **give|up**Для 1.1: левая часть give + правая up. Для 1.3 — последнее слово up.
    **a balanced|diet|balanced**1.1: a balanced + diet; слово для 1.3 — balanced (третий сегмент).

    Правило: **часть1|часть2|слово**. Если третий сегмент не указан — берётся последнее слово.

    🎯 Задания 1.1–1.3

    • 1.1 «Собери выражения» — две колонки с перемешанными частями. Ученик кликает левую часть, затем правую (или перетаскивает). Верная пара собирается вниз, неверная мигает красным.
    • 1.2 «Вставь выражения» — в предложениях пропуски, внизу список выражений. Клик по выражению + клик по пропуску вставляет его.
    • 1.3 «Впиши слово» — в предложениях пропущено слово из выражения. Ученик печатает слово: верное зеленеет и фиксируется, неверное краснеет и его можно исправить.

    Задания 1.1 и 1.2 показываются одинаково у всех — порядок частей и фишек общий, чтобы учитель и ученик смотрели на одно и то же.

    📚 Словарь урока

    Отдельный раздел каждого урока (как задания 1.1–1.3). Соберите в нём выражения прямо из текста:

    • Добавление — выделите нужный фрагмент текста урока мышкой, появится кнопка «＋ В словарь» — нажмите её. Фрагмент сохранится в словарь урока. Повторное добавление того же выражения отклоняется.
    • Перевод — у кнопки ✏️ введите перевод или пояснение (можно и сразу при добавлении через API). Правит учитель или автор записи.
    • Удаление — крестик ✕ у записи; учитель может удалить любую, ученик — только свою.
    • Общий для всех — словарь один на урок: добавленное видят все, кто откроет урок, и оно обновляется в реальном времени.

    В списке уроков у каждого урока показан счётчик «📚 словарь: N». Добавление и удаление попадает в ленту «Активность».

    👁 Видимость заданий

    Настройка на двух уровнях:

    • Общий набор урока — в редакторе урока блок «Видимость заданий» с чекбоксами 1.1 / 1.2 / 1.3. Снятая галочка убирает задание у всех. Хотя бы одно задание должно остаться.
    • Индивидуально для ученика — «Управление» → блок «Видимость заданий»: выберите урок и отметьте галочки напротив каждого ученика. Личная настройка перекрывает общую. Кнопка «Как в уроке» возвращает ученика к общему набору, а «сняты все» — полностью скрывает задания урока у него.

    Сервер сам отклоняет действия по скрытому заданию (400 «Задание скрыто учителем») — прогресс с клиента «подкрутить» не получится.

    📡 Наблюдение в реальном времени

    Пока учитель и ученики в приложении, всё видно без перезагрузки в правой панели:

    • Сейчас онлайн — кто подключён.
    • За работой — по каждому ученику: открытый урок и задание, счётчик N/M и число ошибок.
    • Активность — лента событий: верные ответы зелёным, ошибки красным (с подсказкой, что ожидалось в 1.3).

    🔄 Обновление через Git

    Изменения в код вносятся локально, отправляются в GitHub и подтягиваются на сервере. Полная инструкция — в README.md, раздел «Развёртывание на сервере».

    1. Локально: git add . → git commit -m "…" → git push.
    2. На сервере: cd /opt/english-app → sudo -u www-data git pull origin main.
    3. Если менялись зависимости: .venv/bin/pip install -r requirements.txt.
    4. Перезапуск: sudo systemctl restart english-app.

    🔒 seed.py при обновлении запускать не нужно — иначе демо-данные в базе задвоятся.
